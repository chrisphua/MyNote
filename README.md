# MyNote

A Notion-style block editor that works offline, syncs across iOS and Android, and
lets you build your own theme.

Native on both platforms — SwiftUI on iOS, Jetpack Compose on Android — over a
shared sync protocol and a single Cloudflare Worker backend.

```
iOS (SwiftUI + SwiftData)  ─┐
                            ├─→  Cloudflare Worker  ─┬─→  D1    (notes, blocks, themes, entitlements)
Android (Compose + Room)   ─┘         │              └─→  R2    (attachments, no egress fees)
                                      │
                                      └─→  Firebase Auth  (Google · Apple · email)
```

## Why it is built this way

**Local first, always.** Every edit is written to the device's own database and
the UI returns immediately. Sync is a background consequence, never something
typing waits for. A user with no account and no connection has a fully working
app.

**One sync protocol, three implementations.** `Hlc` and `FractionalIndex` exist
in TypeScript, Swift and Kotlin and must stay byte-identical — shared test
vectors in all three suites enforce it. Conflicts resolve by hybrid logical
clock, so two devices editing offline merge predictably instead of one silently
winning.

**Entitlements key on account, not device.** A purchase made on iOS unlocks the
feature on Android because the server records it against the Firebase `uid` and
nothing else.

**Cheap by construction.** R2 charges nothing for egress, which is the cost that
usually kills a sync app. Free users never touch the backend at all.

## Layout

| Path | What it is |
|---|---|
| `backend/` | Cloudflare Worker: sync API, IAP verification, attachments |
| `ios/MyNoteCore/` | Swift package: sync engine, clocks, ordering, theme model |
| `ios/MyNote/` | SwiftUI app (project generated by XcodeGen) |

## Getting started

```bash
# Backend — runs fully locally against a local D1 and R2
cd backend
npm install
npm run migrate:local
npm run dev
npm test

# iOS — core tests need no simulator
cd ios/MyNoteCore && swift test
cd ios && xcodegen generate && open MyNote.xcodeproj

# Android
cd android
./gradlew :core:test
./gradlew :app:assembleDebug
```

Both apps build and run **without any credentials**. With no
`GoogleService-Info.plist` / `google-services.json` present they start in
local-only mode: notes work, sync and purchases are disabled, and the UI says so.
See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) to wire up the real services.

## Tests

| Suite | Count | Runs in |
|---|---|---|
| `backend` (vitest, real D1) | 35 | ~1s |
| `ios/MyNoteCore` (swift-testing) | 36 | <1s |
| `android/core` (JUnit) | 46 | ~2s |

They cover the things that are expensive to get wrong: conflict resolution,
outbox durability, tenant isolation, cross-platform clock encoding, entitlement
grants and refunds, and the ordering-key invariant.

Several exist because a bug got through. The one guarding an edit made *while a
push is in flight* is the most important in the project — it was verified by
reintroducing the bug and watching it fail.
